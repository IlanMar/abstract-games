# Snake3D: заметки для ИИ-агента

Браузерная 3D-змейка без сборки: `index.html`, `game.js`, `levels.js`, `nsnakes-data.js`. Описание игры — в [README.md](README.md).

## «Создай новый уровень / мир»

Всё для этого уже написано. Не пишите заново инструменты, сборщик, автопилот или помощники сетки.

1. Сначала прочитайте [WORLDS.md](WORLDS.md). Это полный гид: правила движка, нить маршрута, цвета пола, API `tools/grid.js` и таблица всех готовых миров со ссылками на скрипты.
2. Опирайтесь на классические уровни оригинала (карты 22–63): владелец считает их лучшими. Их приёмы перечислены в WORLDS.md, в разделе «Классические уровни — главный образец». Скопируйте самый похожий скрипт из `tools/worlds/` и измените его (таблица «Скрипты» в WORLDS.md подскажет образец). По мотивам классики сделаны `foundry.js`, `launchpad.js` (квадрат) и `prism.js` (гекс); лестница сложности — `lanterns.js` (лёгкий), `clockwork.js` (средний, гекс) и `tightrope.js` (трудный, над пустотой); большие миры 64×64, чья дорога проходит через весь участок, — `reef.js` (лёгкий), `observatory.js` (средний, гекс) и `aqueduct.js` (трудный, над пустотой). Лёгкие односторонние миры: `garden.js`, `blocks.js`, `candy.js`, `carnival.js`. Двусторонние с изнанкой: `weave.js`, `spiral.js`, `hive.js`.
3. Добавьте имя в `WORLDS` в `tools/build-levels.js`, выполните `node tools/build-levels.js` и поднимите `levels.js?v=N` в `index.html`.
4. Проверьте мир в браузере: `autopilot.check(N)` и `autopilot.route(N)` из `tools/autopilot.js`. Номер карты N = 2 + позиция мира в `WORLDS`. Оба отчёта должны быть чистыми.
5. Опишите мир в README.md (раздел «Новые миры») и добавьте строку в таблицу «Скрипты» в WORLDS.md.

Запуск: из корня репозитория `python -m http.server 8765`, игра на `http://localhost:8765/Snake3D/` (в `.claude/launch.json` есть конфигурация `static`).

- `HANDOFF.html` не в git; это подробная передача проекта, её можно обновлять.
