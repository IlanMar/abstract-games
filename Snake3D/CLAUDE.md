# Snake3D: заметки для ИИ-агента

Браузерная 3D-змейка без сборки: `index.html`, `game.js`, `levels.js`, `nsnakes-data.js`. Описание игры — в [README.md](README.md), каталог миров — в [LEVELS.md](LEVELS.md).

## «Создай новый уровень / мир»

Всё для этого уже написано. Не пишите заново инструменты, сборщик, автопилот или помощники сетки.

1. Сначала прочитайте [WORLDS.md](WORLDS.md). Это полный гид: правила движка, нить маршрута, цвета пола, API `tools/grid.js` и таблица всех готовых миров со ссылками на скрипты.
2. Опирайтесь на классические уровни оригинала (группа Classic в меню, после новых миров): владелец считает их лучшими. Их приёмы перечислены в WORLDS.md, в разделе «Классические уровни — главный образец». Скопируйте самый похожий скрипт из `tools/worlds/` и измените его. Таблица «Скрипты» в WORLDS.md описывает каждый мир (форма, размер, сложность, приёмы, найденные ошибки): по ней и выбирайте образец. Для мира на `tools/road.js` (дорога по обеим сторонам, нырки) берите за основу скрипты на `tools/worldkit.js`: `sudoku.js` (квадрат), `moon.js` (гекс с рельефом) и `rosewindow.js` (гекс над пустотой); для поздней классики над пустотой (щиты, туннели, струны с кристаллами, этапы из двух цепочек) — `galleons.js`, `organ.js`, `molecule.js` и `tortoise.js`. Общие куски — дыры на нырках, подсветку, свободные клетки за поворотами, заполнение сторон и проверку «ничего острого рядом с дорогой» — берите из `worldkit.js` (раздел «API `worldkit.js`» в WORLDS.md), а не копируйте. Старые скрипты не переделывайте: `levels.js` должен собираться без изменений. Для открытого мира без маршрута (все предметы сразу, игрок исследует) образцы — `terra.js` (остров), `isles.js` (трудный, острова на мостах) и `planet.js` (мир без края, с рельефом), правила — в разделе «Открытый мир» WORLDS.md.
3. Предметы не обязательно ставить близко: ни цепочки, ни кристаллы-крошки не должны идти вплотную. Цель может быть далеко или за поворотом, лишь бы `autopilot.route` был чистым, то есть цель показывается не позже чем через 8 шагов (WORLDS.md, «Нить маршрута» и «Редкие предметы»).
4. Цвета подбирайте по разделу «Концепция сочетания цветов» в WORLDS.md: одна палитра на мир, дорога самая светлая, поле самое тёмное (в мирах с редкими предметами дорогу не красят совсем).
5. Добавьте имя в `WORLDS` в `tools/build-levels.js`, выполните `node tools/build-levels.js` и поднимите `levels.js?v=N` в `index.html`.
6. Проверьте мир в браузере: `autopilot.check(N)` и `autopilot.route(N)` из `tools/autopilot.js`. Номер карты N = 2 + позиция мира в `WORLDS`. Оба отчёта должны быть чистыми.
7. Опишите мир в LEVELS.md (абзац в конце списка, поднимите номер последнего уровня в первой строке) и добавьте строку в таблицу «Скрипты» в WORLDS.md.

Запуск: из корня репозитория `python -m http.server 8765`, игра на `http://localhost:8765/Snake3D/` (в `.claude/launch.json` есть конфигурация `static`).

- `HANDOFF.html` не в git; это подробная передача проекта, её можно обновлять.
