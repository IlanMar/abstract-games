# abstract-games

Коллекция маленьких браузерных игр. Один файл — одна игра, без сборки и зависимостей.

## Abstract Trader — [index.html](index.html)

**Играть: https://ilanmar.github.io/abstract-games/**

Минималистичный симулятор торговли на бирже: график в реальном времени и две кнопки.

### Правила

* Старт: **$1000 кэшем**, акций нет. Цена бумаги — $10.
* Две кнопки: **Купить 10** и **Продать 10**. Больше ничего делать нельзя.
* График идёт в реальном времени: новая котировка каждые 100 мс, в окне 600 последних баров.
* На кнопке написана цена лота — сразу видно, хватает ли кэша.
* **Банкротство**, если капитал (кэш + акции по текущей цене) падает ниже $100.
* Пунктирная линия — средняя цена вашей позиции. Выше неё вы в плюсе, ниже — в минусе.
* Результат забега — максимум капитала за партию; рекорд свой у каждой бумаги и
  хранится в `localStorage`.
* На десктопе работают стрелки ↑ (купить) и ↓ (продать).

### Выдуманная бумага или настоящая

Левый селектор в шапке переключает источник котировок, правый (для настоящих бумаг) —
месяц, с которого начинается партия. Справа от цены идёт дата текущего бара: она бежит
вперёд по мере игры.

**Выдуманная бумага** — генератор. Геометрическое броуновское движение с переключением
режимов, то есть ровно то, чем обычно моделируют реальную бумагу:

```
price *= exp( drift + PULL * ln(fair / price) + SIGMA * N(0,1) )
```

* `SIGMA` — шум каждого тика: бумага постоянно дёргается вверх-вниз;
* `drift` — текущий тренд. Выбирается случайно и живёт случайное время (2…30 секунд),
  после чего меняется — иногда на противоположный, иногда почти на такой же;
* `PULL` — слабый возврат к справедливой цене: не даёт котировке улететь в ноль или в
  бесконечность, как у реальной бумаги с фундаментальной оценкой.

**Apple, Tesla, Nvidia, GameStop, Coca-Cola, Bitcoin, Сбербанк, Газпром** — настоящие
дневные бары за 10 лет из [data/quotes.js](data/quotes.js) (по 2600 баров на бумагу,
один бар = один торговый день = один тик игры). Можно начать со случайного места или
выбрать месяц: март 2020 — ковидный обвал, январь 2021 — вынос GameStop, февраль 2022 —
обвал Мосбиржи. Окно перед выбранной датой сразу показано как предыстория, поэтому
выбрать можно любой месяц начиная с 600-го бара.

Важная деталь: играем не абсолютной ценой, а **доходностями** бумаги. Цена всегда
стартует с $10 (иначе правило «$1000 на старте» не работало бы для Bitcoin за $80 000),
но каждый следующий тик — настоящее изменение котировки. Форма графика, волатильность,
тренды и обвалы — подлинные, уровень цены — нормированный. Поэтому у каждой бумаги свой
характер: Coca-Cola дремлет, Tesla швыряет.

Когда цена вырастает вдвое, происходит **дробление акций 2:1** — ровно то, что делают
настоящие эмитенты: цена пополам, акций вдвое больше, капитал не меняется, форма графика
тоже. Без этого за пару минут игры на дневных данных цена уезжала бы в разы и лот из
10 акций становился неподъёмным.

Когда история заканчивается, она идёт по кругу; на склейке применяется нулевая
доходность, чтобы не было разрыва цены.

### Обновить котировки

```bash
node tools/fetch-quotes.mjs
```

Скрипт тянет дневные бары из Yahoo Finance (американские бумаги и BTC) и из MOEX ISS
(российские) и перезаписывает `data/quotes.js` — ~190 КБ на все восемь бумаг
(около 60 КБ по проводу: GitHub Pages отдаёт его сжатым).
Ключи не нужны. Данные загружаются обычным `<script>`, поэтому игра работает и с
`file://`, и на GitHub Pages, без CORS и запросов в рантайме.

### Производительность

* Котировки лежат в кольцевом буфере `Float32Array(600)` — фиксированные 2.4 КБ,
  никаких аллокаций и сборок мусора во время игры.
* Один `requestAnimationFrame`-цикл: логика идёт по фиксированному шагу 100 мс,
  отрисовка — по кадрам, с интерполяцией по доле тика (поэтому график едет плавно).
* DOM обновляется не чаще, чем раз в тик, а не каждый кадр.
* Свёрнутая вкладка не «догоняет» пропущенные тики — игра не может проиграться в фоне.

## Откуда брать реальные котировки

Коротко: **исторические данные — бесплатно и легко, настоящий real-time по акциям —
платно и с лицензией биржи.** Бесплатные тарифы дают задержку 15 минут.

| Источник | Что даёт | Нюанс |
|---|---|---|
| **MOEX ISS** — `iss.moex.com/iss/.../candles.json?interval=24` | Свечи по российским бумагам от 1 минуты, вся история | Полностью открытый API без регистрации, отдаёт CORS-заголовки. Используется здесь |
| **Yahoo Finance** — `query1.finance.yahoo.com/v8/finance/chart/AAPL?range=10y&interval=1d` | Дневные бары за десятилетия, часовые за год, минутные за ~месяц | Неофициальный эндпоинт: без CORS, с лимитами, требует User-Agent браузера, может сломаться в любой момент. Используется здесь |
| **Binance** — `api.binance.com/api/v3/klines` + `wss://stream.binance.com` | Минутные свечи и **настоящий real-time по WebSocket** | Бесплатно и без ключа, но это крипта, а не акции |
| **Stooq** — `stooq.com/q/d/l/?s=aapl.us&i=d` | Дневные OHLCV одной CSV-ссылкой | Больше не годится для скриптов: закрыт JS-проверкой браузера |
| **Twelve Data, Alpha Vantage, Finnhub, Polygon, Tiingo, EODHD** | REST + у части WebSocket, CORS разрешён | Нужен ключ; лимиты от ~25 запросов в день до ~800; по акциям данные с задержкой |

Биржевые данные лицензируются: бесплатно раздают задержанные котировки, а их
перепубликация обычно ограничена условиями API. Здесь лежит небольшой учебный срез
истории — для игры этого достаточно, для чего-то серьёзного стоит смотреть на условия
конкретного провайдера.
