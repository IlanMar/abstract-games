# abstract-games

Коллекция маленьких браузерных игр. Один файл — одна игра, без сборки и зависимостей.

## Abstract Trader — [index.html](index.html)

Минималистичный симулятор торговли на бирже. Открыть можно двойным кликом по файлу
(или отдать любым статическим сервером, например `python -m http.server`).

### Правила

* Старт: **100 акций** ABST по $10 (на $1000) и **$1000 кэша** — капитал $2000.
* Две кнопки: **Купить 10** и **Продать 10**. Больше ничего делать нельзя.
* График идёт в реальном времени: новая котировка каждые 100 мс, в окне 60 секунд истории.
* **Банкротство**, если капитал (кэш + акции по текущей цене) падает ниже $100
  или если акций не осталось, а кэша не хватает даже на один лот.
* Пунктирная линия — средняя цена вашей позиции. Выше неё вы в плюсе, ниже — в минусе.
* Лучший и последний результат (максимум капитала за забег) хранятся в `localStorage`.
* На десктопе работают стрелки ↑ (купить) и ↓ (продать).

### Как устроена цена

Цена — геометрическое броуновское движение с переключением режимов; именно так обычно
и моделируют поведение реальной бумаги:

```
price *= exp( drift + PULL * ln(fair / price) + SIGMA * N(0,1) )
```

* `SIGMA` — шум каждого тика: бумага постоянно дёргается вверх-вниз;
* `drift` — текущий тренд. Он выбирается случайно и живёт случайное время
  (2…30 секунд), после чего меняется — иногда на противоположный, иногда почти на такой же;
* `PULL` — слабый возврат к справедливой цене: не даёт котировке улететь в ноль
  или в бесконечность, как у реальной бумаги с фундаментальной оценкой.

При старте буфер заполняется «предысторией» — тот же процесс, проигранный назад от
текущей цены, чтобы график с первой секунды выглядел живым.

### Производительность

* Котировки лежат в кольцевом буфере `Float32Array(600)` — фиксированные 2.4 КБ,
  никаких аллокаций и сборок мусора во время игры.
* Один `requestAnimationFrame`-цикл: логика идёт по фиксированному шагу 100 мс,
  отрисовка — по кадрам, с интерполяцией по доле тика (поэтому график едет плавно).
* DOM обновляется не чаще, чем раз в тик, а не каждый кадр.
* Свёрнутая вкладка не «догоняет» пропущенные тики — игра не может проиграться в фоне.

## Можно ли подключить реальные котировки?

Да. Коротко: **исторические данные — бесплатно и легко, реальный real-time по акциям —
платно и с лицензией биржи.** Бесплатные тарифы дают задержку 15 минут.

### Без ключа, прямо из браузера

| Источник | Что даёт | Нюанс |
|---|---|---|
| **MOEX ISS** — `iss.moex.com/iss/engines/stock/markets/shares/boards/TQBR/securities/SBER/candles.json?interval=1&from=2024-01-01` | Свечи по российским бумагам от 1 минуты, вся история | Полностью открытый API без регистрации, отдаёт CORS-заголовки |
| **Stooq** — `stooq.com/q/d/l/?s=aapl.us&i=d` | Дневные OHLCV по США/Европе, CSV одной ссылкой | CORS нет — качать файлом, а не `fetch()` |
| **Binance** — `api.binance.com/api/v3/klines?symbol=BTCUSDT&interval=1m` + `wss://stream.binance.com` | Минутные свечи и **настоящий real-time по WebSocket** | Это крипта, а не акции. Зато честный тик в реальном времени и бесплатно |
| **Yahoo Finance** — `query1.finance.yahoo.com/v8/finance/chart/AAPL?range=1mo&interval=1m` | Минутные бары за ~30 дней, дневные — за десятилетия | Неофициальный эндпоинт: без CORS, с лимитами, может сломаться в любой момент |

### С бесплатным ключом

* **Twelve Data**, **Alpha Vantage**, **Finnhub**, **Polygon.io**, **Tiingo**, **EODHD** —
  REST + (у части) WebSocket, CORS разрешён, ключ можно держать в браузере только для
  учебного проекта. Лимиты жёсткие (от ~25 запросов в день у Alpha Vantage до ~800 у
  Twelve Data), котировки по акциям — с задержкой; уточняйте актуальные тарифы.

### Что имеет смысл сделать здесь

Игре не нужен живой поток — ей нужна **правдоподобная траектория**. Поэтому практичнее
всего «режим реальной бумаги»:

1. один раз скачать минутные бары (например, `SBER` с MOEX ISS или `AAPL` с Yahoo),
   сохранить в репозиторий как `data/aapl-1m.json`;
2. в игре заменить только источник цены в `step()` — вместо генератора брать следующее
   значение из массива, с нужным ускорением (1 минута истории = 1 тик игры);
3. остальной код (буфер, отрисовка, сделки, банкротство) не меняется вообще.

Плюсы: игра остаётся офлайновой, без ключей, CORS и лимитов, а поведение графика —
буквально биржевое. Минус: траектория повторяется от партии к партии — лечится случайным
выбором бумаги и случайной точкой старта внутри истории.

Про живой real-time по акциям стоит помнить, что биржевые данные лицензируются: бесплатно
раздают задержанные котировки, а их перепубликация обычно ограничена условиями API.
