# abstract-games

Коллекция маленьких браузерных игр. Одна игра — одна папка, без сборки и зависимостей.
Витрина со списком лежит в корне — [index.html](index.html), она же
**https://ilanmar.github.io/abstract-games/**

## Abstract Trader — [trader/](trader/index.html)

**Играть: https://ilanmar.github.io/abstract-games/trader/**

Минималистичный симулятор торговли на бирже: график в реальном времени и две кнопки.

### Правила

* Старт: **100 акций и ноль кэша** в режиме настоящих котировок или **$1000 кэшем**
  без акций, если цена приведена к $10.
* Две кнопки: **Купить 10** и **Продать 10**. Больше ничего делать нельзя.
* График идёт в реальном времени: новый бар каждые 100 мс, в окне 600 последних баров.
* На кнопке написана цена лота — сразу видно, хватает ли кэша.
* **Банкротство**, если капитал (кэш + акции по текущей цене) усох до десятой части
  стартового.
* Пунктирная линия — средняя цена вашей позиции. Выше неё вы в плюсе, ниже — в минусе.
* **Без сделок** — сколько было бы, если бы стартовый капитал просто лежал в акциях и его
  не трогали. Обгонять это число и есть вся игра: продать выше и откупить ниже.
* По горизонтали идёт время: месяцы для реальной истории, секунды для выдуманной бумаги.
* Результат забега — максимум капитала за партию, он показывается на экране проигрыша.
  В `localStorage` запоминается последний выбор бумаги и режима.
* На десктопе работают стрелки ↑ (купить) и ↓ (продать).

### Выдуманная бумага или настоящая

Селекторы в шапке: бумага, год и месяц начала партии, режим цены. Справа от цены идёт
дата текущего бара — она бежит вперёд по мере игры.

**Выдуманная бумага** — генератор. Геометрическое броуновское движение с переключением
режимов, то есть ровно то, чем обычно моделируют реальную бумагу:

```
price *= exp( drift + PULL * ln(fair / price) + SIGMA * N(0,1) )
```

* `SIGMA` — шум каждого тика: бумага постоянно дёргается вверх-вниз;
* `drift` — текущий тренд. Выбирается случайно и живёт случайное время (2…30 секунд),
  после чего меняется — иногда на противоположный, иногда почти на такой же;
* `PULL` — слабый возврат к справедливой цене: не даёт котировке улететь в ноль или в
  бесконечность, как у реальной бумаги с фундаментальной оценкой.

**Настоящие бумаги** — дневные бары, один бар = один тик игры. Глубина истории у каждой
своя, вся доступная:

| Бумага | История | Баров |
|---|---|---|
| Apple, Coca-Cola, Intel | с 1990 | 9242 |
| Nvidia | с 1999 | 6953 |
| GameStop | с 2002 | 6185 |
| Google | с 2004 | 5552 |
| Газпром | с 2006 | 5295 |
| Сбербанк | с 2007 | 4923 |
| Bitcoin | с 2014 | 4381 |
| Tesla | с 2010 | 4077 |

Партия начинается со случайного места или с выбранного месяца: сентябрь 2000 — обвал
Apple на 52% за день, март 2020 — ковид, январь 2021 — вынос GameStop, февраль 2022 —
обвал Мосбиржи. Окно перед выбранной датой сразу показано как предыстория, поэтому
выбрать можно любой месяц начиная с 600-го бара.

### Два режима цены

**«как есть»** (по умолчанию) — настоящие котировки без нормировки. Стартовый
капитал тогда не в деньгах, а в бумагах: **100 акций и ноль кэша**. Для Google в
сентябре 2008-го это $1 162, для биткоина — $10.4M. Лот из 10 акций — это всегда ровно
10% стартового капитала, так что игра ощущается одинаково на любой бумаге.

Валюта у каждой бумаги своя: Сбербанк и Газпром торгуются на Мосбирже в рублях, поэтому
и цена, и счёт в этом режиме считаются в ₽ (21 февраля 2022-го — 201 ₽ за акцию и
20 100 ₽ капитала). Никакой конвертации в доллары нет: для неё понадобился бы
исторический курс, а это уже другая задача.

**«к $10»** — играем не абсолютной ценой, а **доходностями** бумаги: цена
стартует с $10, а рядом с ней в скобках приглушённо показана настоящая котировка этого
дня — в родной валюте бумаги, `(252.11 ₽)` для Сбербанка. Сам счёт здесь всегда
долларовый, потому что $10 — это не цена, а масштаб. В этом режиме правило «$1000 на старте» работает одинаково для Coca-Cola и для
биткоина за $80 000, у которого один лот стоил бы дороже всего депозита.

В обоих режимах каждый следующий тик — настоящее изменение котировки. Форма графика,
волатильность, тренды и обвалы подлинные, у каждой бумаги свой характер: Coca-Cola
дремлет, Tesla швыряет.

В нормированном режиме, когда цена уходит вдвое вверх или вниз, происходит **дробление
или консолидация акций** — ровно то, что делают настоящие эмитенты: цена пополам, акций
вдвое больше (или наоборот), капитал не меняется, форма графика тоже. Без этого за пару
минут игры цена уезжала бы в разы и лот из 10 акций становился бы либо неподъёмным, либо
бессмысленно мелким. На настоящих котировках дробления, разумеется, нет.

Когда история заканчивается, она идёт по кругу; на склейке применяется нулевая
доходность, чтобы не было разрыва цены.

### Обновить котировки

```bash
node trader/tools/fetch-quotes.mjs
```

Скрипт тянет дневные бары из Yahoo Finance (американские бумаги и BTC) и из MOEX ISS
(российские) и перезаписывает `trader/data/`: индекс со списком бумаг и по файлу на бумагу.
Запускать можно из любой папки — пути скрипт считает от самого себя.
Ключи не нужны.

Две грабли, на которые он уже наступил:

* у Yahoo нужно запрашивать `period1`/`period2`, а не `range=max` — с `range=max` он
  молча отдаёт **месячные** бары вместо дневных;
* и обязательно подставлять браузерный `User-Agent`, иначе в ответ прилетает 429.

Файлы грузятся по требованию обычным `<script>`: при старте игра тянет только индекс
(218 байт) и одну бумагу (40–95 КБ), остальные — когда их выберут. Поэтому игра работает
и с `file://`, и на GitHub Pages, без CORS и запросов к API в рантайме.

### Производительность

* Котировки лежат в кольцевом буфере `Float32Array(600)`, рядом коды месяцев в
  `Uint16Array(600)` — фиксированные 3.6 КБ, никаких аллокаций и сборок мусора во время игры.
* Один `requestAnimationFrame`-цикл: логика идёт по фиксированному шагу 100 мс,
  отрисовка — по кадрам, с интерполяцией по доле тика (поэтому график едет плавно).
* DOM обновляется не чаще, чем раз в тик, а не каждый кадр.
* Свёрнутая вкладка не «догоняет» пропущенные тики — игра не может проиграться в фоне.

## Откуда брать реальные котировки

Коротко: **исторические данные — бесплатно и легко, настоящий real-time по акциям —
платно и с лицензией биржи.** Бесплатные тарифы дают задержку 15 минут.

| Источник | Что даёт | Нюанс |
|---|---|---|
| **MOEX ISS** — `iss.moex.com/iss/.../candles.json?interval=24` | Свечи по российским бумагам от 1 минуты, вся история | Полностью открытый API без регистрации, отдаёт CORS-заголовки. Используется здесь |
| **Yahoo Finance** — `query1.finance.yahoo.com/v8/finance/chart/AAPL?period1=…&period2=…&interval=1d` | Дневные бары за десятилетия, часовые за год, минутные за ~месяц | Неофициальный эндпоинт: без CORS, с лимитами, требует User-Agent браузера, может сломаться в любой момент. Используется здесь |
| **Binance** — `api.binance.com/api/v3/klines` + `wss://stream.binance.com` | Минутные свечи и **настоящий real-time по WebSocket** | Бесплатно и без ключа, но это крипта, а не акции |
| **Stooq** — `stooq.com/q/d/l/?s=aapl.us&i=d` | Дневные OHLCV одной CSV-ссылкой | Больше не годится для скриптов: закрыт JS-проверкой браузера |
| **Twelve Data, Alpha Vantage, Finnhub, Polygon, Tiingo, EODHD** | REST + у части WebSocket, CORS разрешён | Нужен ключ; лимиты от ~25 запросов в день до ~800; по акциям данные с задержкой |

Биржевые данные лицензируются: бесплатно раздают задержанные котировки, а их
перепубликация обычно ограничена условиями API. Здесь лежит небольшой учебный срез
истории — для игры этого достаточно, для чего-то серьёзного стоит смотреть на условия
конкретного провайдера.
